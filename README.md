# Grade-Calculator
Grade Calculator for CST 205

This project helps instructors calculate their students grades for a single course.

The program stores students names and grades in a dictionary, and calculates each student's average grade, assigns an overall letter grade, and identifies the top performer in the class. It also identifies the passing quantity on a scale from A-F set as the thresholds.

**Features**
Stores student grades in a python dictionary
Calculates the average grade for each student
Assigns letter grades based on standard grading scale
Finds students with the highest average
Counts the number of students who received a C or better
Displays results in terminal

**Requirements**
VS Code
Python

**How to Run**
Open project in preferred code editor
Insert grades into the dictionary
Run the program
